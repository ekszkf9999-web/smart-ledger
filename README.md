# 하이브리드 가계부

급여일 기준으로 한 달을 끊어 **수입 → 고정생활비 → 대출 → 저축·투자 → 변동 소비**를 나눠 보고,
**카드별 예상 청구액**과 **통장별 필요 잔액**까지 한 화면에서 확인하는 오프라인 모바일 가계부입니다.

- 앱 주소(배포 후): `https://<GitHub아이디>.github.io/smart-ledger/`
- 버전: **v1.0.0**
- 모든 기록은 브라우저 `localStorage`에만 저장됩니다. 서버 전송 0건, 회원가입 없음.
- 인터넷이 끊겨도 실행됩니다(서비스워커 캐시 `smart-ledger-v1`).

## 화면 구성

| 탭 | 내용 |
| --- | --- |
| **요약** | 이번 기간 가용 잔액·저축률, 5줄 요약(수입/고정비/대출/저축·투자/변동), 현금흐름 3분할(계좌 고정비·카드 고정비·카드 변동), 카드별 예상 청구액, 통장별 필요 잔액 |
| **고정·계획** | 월급·관리비·대출·적금 같은 반복 항목을 결제일(매월 1~31일 / 매주 요일) 순으로 정렬. 완료 체크, 수정·삭제, 항목 추가 |
| **변동·일상** | 금액·날짜·분류·결제수단·메모를 넣는 빠른 입력(엔터로 저장), 즐겨찾기 원터치 기록·추가/수정, 메모 키워드 자동 분류(스타벅스→카페, 코스트코→장보기 등), 카테고리 예산 진행률, 최근 내역 수정·삭제 |
| **설정·백업** | 월 시작일(급여일, 1~28일), 통장·카드 추가/수정/삭제, 카테고리 이름·예산·소분류 편집, 자주 쓰는 내역 관리, JSON 백업/복원, 월별 CSV, 예시로 채우기/빈 장부로 시작/전체 비우기 |

### 월 시작일(급여일) 기준

급여일이 25일이면 한 달은 **10.25 ~ 11.24**처럼 이어집니다.
 달 이름은 기간의 과반이 들어 있는 달을 따르므로, 위 기간은 **11월**로 표시됩니다.
(1일로 설정하면 평소처럼 11.1 ~ 11.30)

### 이중 집계 방지

- 변동 소비 통계에는 이번 기간 카드 사용액이 들어갑니다.
- 카드별 예상 청구액은 **카드 고정비 + 카드 변동 사용액**으로 따로 계산하며, 소비 요약에 다시 더하지 않습니다.
- 통장별 필요 잔액은 **그 통장의 계좌 고정비 + 연결 카드 청구 예상액**입니다. 이미 나간 변동 지출과 현금 지출은 제외합니다.
- 저축·투자는 소비가 아니라 **자산 이동**으로 따로 표시하되, 통장에서 나가는 돈이라 총 출금·가용 잔액에는 포함합니다.

## GitHub Pages 배포

1. GitHub에서 **`smart-ledger`** 이름의 공개 저장소를 만듭니다.
   - 저장소 만들기: <https://github.com/new?name=smart-ledger&description=%ED%95%98%EC%9D%B4%EB%B8%8C%EB%A6%AC%EB%93%9C+%EA%B0%80%EA%B3%84%EB%B6%80&visibility=public>
2. 이 폴더의 파일을 저장소 루트에 올립니다(`index.html`이 루트에 오도록).
3. 저장소 **Settings → Pages → Build and deployment**에서
   **Source: Deploy from a branch**, **Branch: `main` / `/ (root)`** 로 저장합니다.
4. 1~2분 뒤 `https://<GitHub아이디>.github.io/smart-ledger/` 가 열립니다.

```bash
# 이 폴더에서 (저장소를 이미 만들고 원격을 연결한 경우)
git init
git add -A
git commit -m "hybrid ledger v1.0.0"
git branch -M main
git remote add origin https://github.com/<GitHub아이디>/smart-ledger.git
git push -u origin main
```

### 폰에 앱처럼 설치

- **Android Chrome**: 주소 접속 → 오른쪽 위 ⋮ → **설치 및 바로가기 만들기** → 설치
- **iPhone Safari**: 공유 → **홈 화면에 추가**
- 한 번 열어 두면 비행기 모드에서도 실행됩니다. 새 버전을 올리면 온라인 상태로 한 번 열었다가 다시 열면 자동 반영됩니다. (강제 갱신이 필요하면 `sw.js`의 `CACHE` 이름을 `smart-ledger-v2`로 올려 배포하세요.)

## 백업과 개인정보

- **JSON 내보내기**: 항목·내역·설정 전체. 기기를 바꾸거나 초기화 전에 보관하세요.
- **JSON 불러오기**: 현재 데이터를 덮어씁니다(확인 창이 뜹니다).
- **CSV 내보내기**: 이번 기간의 고정 항목(회차별 날짜)과 변동 내역을 엑셀에서 열 수 있게 내보냅니다(UTF-8 BOM).
- 브라우저 방문 기록/사이트 데이터를 지우면 기록도 사라집니다. 정기적으로 JSON 백업을 권장합니다.
- 샘플 데이터는 `월급`, `아파트 관리비`, `주택대출`처럼 **완전히 일반화된 예시**이며, 실제 개인정보·계좌·카드 조합은 코드에 없습니다.
